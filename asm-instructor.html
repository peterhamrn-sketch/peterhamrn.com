ASM Instructor

A practical class-management application designed to help instructors move from the original roster to a complete, accurate class record without juggling multiple spreadsheets and paper processes.

Current TEST release: Version 7.0.0-test · Release R204 · Build 414

One app for the full class workflow

ASM Instructor keeps the original roster, check-in information, scores, skills completion, attendance status, class files, and final export together in one place.

1

Import the official roster

Load the original Road Guardians spreadsheet while preserving the class information and source file for later reference.

2

Run student check-in

Search for each student, confirm contact details, correct information when needed, and add walk-ins or late additions.

3

Track class progress

Record pre-test and post-test scores, skills-sheet completion, attendance, and no-show status throughout the class.

4

Keep the class files

The original spreadsheet and completed spreadsheet remain associated with the class instead of being scattered across downloads and folders.

5

Complete and lock the class

Review the final class record, correct errors before completion, and lock the class to protect the finished information.

6

Export the finished record

Create a completed spreadsheet containing the students who attended, including test scores and skills completion.

7

Build useful student history

Keep a searchable student database and class history so prior attendance and contact information remain available for future work.

8

Keep photos and recovery tools together

Associate class photos and files with the class, preserve backups, and use recovery points when an instructor needs to restore working data.

9

Manage class communication

Use Communication Center for announcements, contacts, reviewed campaigns, and explicit publishing of public class information.

Designed around real instructor needs

  • Preserves the original roster and filename
  • Supports checked-in students, no-shows, and walk-ins
  • Tracks pre-test scores, post-test scores, and skills sheets
  • Allows corrections before the class is finalized
  • Keeps completed class records available for later review
  • Maintains a searchable student database and course history
  • Stores class photos and provides backup and recovery tools
  • Publishes selected upcoming-class information to PeterHamRN.com only when explicitly requested
  • Supports ongoing improvements based on instructor feedback
