Professional website for Peter Ham, BSN, RN.

## Current release

Version 1.0

## Deployment

This is a static website. Deploy the repository root from the `main` branch with no build command.

For Cloudflare Pages:

- Production branch: `main`
- Build command: leave blank
- Build output directory: `/`

Every future commit to `main` will trigger a new deployment after the repository is connected to Cloudflare Pages.
